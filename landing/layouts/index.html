API docs you can build

pydoc_fork focuses on turning importable modules into a folder of HTML. Run it during a build, then serve the files from any static host.

02 / USE IT

Point at a module.
Get a site.

Start with a module name and an output directory. Add a theme, project label, or configuration file when your docs need them.

● ● ●terminal01 / CLI
# Generate documentation for a package
$ pydoc_fork my_module --output docs

# Choose the dark theme and a project label
$ pydoc_fork my_module --output docs \
    --theme dark --project_name "My Cool Lib"

# Configure options in pyproject.toml
$ pydoc_fork my_module --config .
